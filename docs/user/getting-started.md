# Garage User Guide

Garage helps you keep a clean record of everything that happens to your car. The app is designed for owners who want useful history without extra complexity.

## First Steps

1. Sign in with Apple or Google.
2. Add your first vehicle.
3. Enter the current odometer reading.
4. Start with an oil change or fuel fill-up so the dashboard has real data.

## What You Can Do

- Log maintenance, repairs, track days, fuel, tires, brakes, alignments, upgrades, and oil analysis
- Save receipts and photos
- Watch wear items and reminders
- Export a resale-ready report with your history and photos

## Free vs Pro

- Free: one vehicle, core logging, odometer tracking, basic wear dashboard
- Pro: unlimited vehicles, reminders, attachments, exports, gallery, detailing, parts, warranty, recalls, stats, and AI-assisted oil analysis

## Offline Use

- Garage keeps a local cache and stores work if you lose signal.
- If something cannot sync, the app shows it clearly and lets you retry.

## Help Terms

- `Heat cycles`: how many hard track sessions a tire set has gone through
- `DME report`: an engine event report, commonly used on performance cars
- `Oil analysis`: a lab report showing engine wear metals and contamination
